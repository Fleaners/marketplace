# Figma-Ready Component Library

## Core Layout Components
- App Shell
- Top Bar (title, profile, theme toggle)
- Bottom Navigation (5 tabs max)
- Section Header (title + one primary action)

## Cards
- Metric Card
  - Title
  - Number
  - Meta trend
- Action Card
  - Title
  - Supporting line
  - CTA button
- Story Card
  - Insight statement
  - Optional badge
- Product Card
  - Image
  - Product title
  - Price
  - Stock status
  - Views
  - Inquiries
  - Quick actions

## Buttons
- Primary: accent background
- Secondary: neutral background
- Ghost: outline only
- Danger: alert action
- Icon button: 44x44 minimum touch target

## Form Components
- Input
- Select
- Multi-line text area
- CSV/Excel file upload drop zone
- Quick filter chips

## Status Components
- In Stock: green
- Running Low: amber
- Out of Stock: red

## Feedback Components
- Empty state card
- Toast
- Inline error
- Skeleton loader
- Offline sync badge

## Chart Components
- Story-first headline summary card
- Line chart card
- Bar chart card
- Pie chart card
- Chart legend chip group

## Messaging Components
- Conversation preview card
- Reply composer
- Quick replies (chips)
- Response SLA reminder

## Profile Components
- Business profile card
- Verification badge
- Payment setup status card
- Help center card

## Design QA Checklist
- No screen has more than one primary CTA above the fold.
- No table-first pages for sellers.
- Every metric has plain-language explanation.
- All interactive controls meet 44x44 touch size.
- All text contrast meets WCAG AA.
